# Connect Hub 1.0.3

- На телефонах прокручивается рабочая область под закреплённой шапкой. Верхняя безопасная зона Safari на iOS имеет непрозрачный фон.
- Убран повторный заголовок над созданием инбаунда. Кнопка «Назад к ключам» получила графитовую подложку и лаймовую стрелку.
- Обновлено оформление индикаторов инбаундов, статусов клиентов, скорости передачи, средней нагрузки ЦП и выбора периода графиков.

Установщик Windows и архив панели Linux публикуются вместе с контрольными суммами SHA-256.
