# Connect Hub 1.0.1

- Mobile header and shared navigation use an animated active section. The active capsule supports horizontal dragging and keeps the Network menu available.
- The overview uses compact version chips and traffic summaries. Total traffic can switch between dot and line charts using the same measured history.
- Active keys show live Sudoku upload and download rates from the native counters, with separate display states for zero traffic and unavailable statistics.
- The panel uses shared lime, graphite, and silver component styles. The mobile inbound carousel remains available.

The Windows x64 installer and Linux panel package support upgrading an existing Connect Hub installation.
