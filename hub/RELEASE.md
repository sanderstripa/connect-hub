Connect Hub 0.8.8 — Tunnels, Logs and Network Tools

- Add managed WatTunnel tunnels with TCP, UDP, TLS, WebSocket and Linux ICMP transports, process isolation, remote-node management, safety checks and failover.
- Add Clean IP scanning and DNS-tunnel administration (StormDNS/dnstt profiles, resolver checks and client links).
- Add read-only Logs page with filtering, statistics, charts, country visualization and controlled log-file access.
- Add REALITY Watch for automatic, tested target recovery and replacement when configured REALITY targets fail.
- Add an opt-in MCP API for authenticated automation of supported Connect Hub operations.
- Add subscription-server per-client rate limiting, client-table column visibility and DNS server drag-to-reorder controls.
- Add UI options for seven accent colors, a glass effect and following the operating-system appearance.
- Preserve existing Connect Hub installation, native Sudoku integration, settings, data, user credentials, subscriptions, themes, and the Windows client.
- WatTunnel is included only for platforms with a verified compatible binary; unsupported platforms can administer remote tunnels.
- Existing installations remain on their current release until explicitly upgraded. Back up configuration and database before updating a production server.

Notes:
- Features from additional upstream 3x-ui pull requests that are not yet ported are not claimed in this release.
- Consult the included admin documentation before configuring privileged network transports.
