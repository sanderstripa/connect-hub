# Connect Hub 1.0.4

- Панель поиска, фильтрации и сортировки прокручивается вместе со списком ключей.
- Информация о клиенте сгруппирована по назначению. На широком экране блоки располагаются в две колонки. Длинные идентификаторы переносятся рядом с кнопкой копирования.
- В карточке клиента отображается текущая скорость при наличии данных.
