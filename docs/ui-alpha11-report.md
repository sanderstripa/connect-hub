# Connect Hub alpha.11 UI refinement

## CH-01–CH-08

| Item | Delivered |
| --- | --- |
| CH-01 | Clients is one standalone navigation item. Group navigation, palette entry, form fields, filters, bulk controls and columns are hidden. Legacy `/groups` redirects to `/clients`. Database records, API, Xray logic and existing group values are retained. Editing a client preserves its group. |
| CH-02 | Inbounds/Clients summary body height is 76 px on desktop, with content-driven wrapping on narrow screens. Every previous metric remains. |
| CH-03 | Small localized page heading, summary, toolbar and table retain the existing spacing scale. Mobile headings leave space for the menu button. |
| CH-04 | Montserrat retained. Section headings 18 px, summary values 20 px, labels 12 px; palette uses consistent 13 px text and equal weights in both themes. No global enlargement. |
| CH-05 | Unlimited traffic/expiry use neutral colors. Active, warning and error states retain their meaning. Dashboard and graphs are unchanged. |
| CH-06 | Compact content-sized palette, scroll cap, aligned input, localized footer, no Groups command. Existing entity search and keyboard handling retained. |
| CH-07 | Clients has no disclosure arrow. Other folders remain. Long labels wrap within the existing sidebar width and standalone items expose full titles. |
| CH-08 | Alpha.10 table geometry, columns and non-group actions retained. Inbounds desktop rows remain below 64 px; mobile keeps the existing card view. |

## Validation

- TypeScript and ESLint passed; frontend production build passed.
- Seven focused Vitest files: **27 tests passed**, including sidebar, palette keyboard/entity search, form flow, bulk renewal and translation key checks.
- Client form regression explicitly verifies that a hidden pre-existing group survives saving.
- Isolated native panel and Playwright: light/dark themes at 1920×1080, 1440×900 and 390×900; Clients/Inbounds render, summaries wrap, legacy route redirects, Clients navigation and palette Enter work, no page exceptions.
- Real local API client create/update/enable/delete using a disabled loopback inbound and disposable database; group remains stored. No real server, user database or VPN traffic is involved.
- Browser also exercises the actual client switch and narrow-screen palette. Screenshots are generated by `hub/ui-alpha11-browser.mjs`.

- `frontend/src/test/{ui-refinement,client-form-flow}.test.tsx`, `hub/ui-{alpha11,point-fixes,refinement}-browser.mjs`: regression coverage.
- Thirteen `internal/web/translation/*.json` files: remove unused Client List menu label; footer reuses existing localized palette title.
- Version, installer package/lock, README translations, NOTICE and release notes: alpha.11 publication metadata.

## Scope and limits

No backend or database migration, authentication, protocol, server configuration or Dashboard redesign. Hidden group management can be restored later without deleting stored data. These checks validate the UI and local management operations; they do not constitute new VPN transport testing or a test on the owner's live VPS. Windows installer remains unsigned, as in alpha.10.

Publication is completed only when the alpha.11 release contains the Linux archive, Windows EXE and matching checksums, with the archive build revision verified against the merged source commit.
