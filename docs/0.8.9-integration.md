# Connect Hub 0.8.9 — completed integration matrix

Connect Hub 0.8.9 integrates eleven requested feature families into the existing Connect Hub panel and Windows installer, retaining the native Sudoku, WatTunnel, DNS tunnels, Clean IP, REALITY Watch, logs, credentials, subscriptions, existing profiles and settings from 0.8.8.

| Feature | Integrated capability | Upstream sources |
|---|---|---|
| Telegram administration | Presets, renewals, admin workflows, individual links, QR, guides, backups | 3x-ui #7012, #6952, #7092 |
| WeCom/webhooks | Settings, delivery, connectivity tests and error reporting | #7086 |
| Client lifetime history | Traffic windows, per-node statistics, changes and card viewer | #7031 |
| Client group Hosts | Group creation, edit, scoped Hosts bindings, subscription and Clash filtering | #7064 |
| ISP-side REALITY Finder | Candidate probe command, remote scan, expiring report and target selection | #7048 |
| Remote node restart | Authorized Xray and panel restart operations and UI confirmations | #6970 |
| Network interface metrics | Automatic, legacy and manual source selection saved to panel settings | #6972 |
| Adaptive client UI | Viewport-fit table, configurable columns and mobile filters | #7083, #7085 |
| Subscription enhancements | Inbound placeholders, host ordering, Rabbit-Hole UA, updated links | #7046, #6969, #7063 |
| AmneziaWG / TUIC | Optional per-peer IPv4 echo policy, SNI, peer sync and transport improvements | #6958, #7043, #6985, #7088 |
| Built-in AI assistant | Optional server-configured, admin-authenticated, advice-only HTTPS chat; keys stay on server | Connect Hub implementation |

## Validation

- Full frontend suite: 2,191 tests passed on the 0.8.9 candidate.
- Go integration and type checks, Windows installer and Docker builds: passed.
- WatTunnel transport/process suite: passed on Windows x64, Linux x64 and Linux ARM64.
- Actual browser smoke: passed with native Sudoku connections, key/QR creation, edit, RU/mobile rendering, navigation, responsive densities and themes in the feature branch.
- The browser fast lab uses a previously built binary and the authored latest palette CSS for targeted UI verification. Production packages must still pass the normal release and post-publication smoke workflows.

For an existing 0.8.8 installation, back up the database, configuration and certificate files before installing 0.8.9. New settings and tables might not be understood by an older binary. See hub/RELEASE.md for feature descriptions and configuration details.
