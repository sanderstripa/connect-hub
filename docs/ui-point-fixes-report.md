- CH-01: заголовок «Клиенты» сразу открывает `/clients`; область стрелки раскрывает подразделы отдельно. «Группы» и старые маршруты сохранены.
- CH-02: вложенные desktop/drawer/popup-меню используют существующие поверхности и цвета темы; активный пункт и раскрытый раздел различимы.
- CH-03: у таблицы входящих убран лишний верхний отступ, уменьшены отступы контейнера и высота строк на основе существующих control/gap переменных. В браузере строка 57 px вместо 64 px, оба состояния темы. Данные и действия не удалены.
- CH-04: синие цвета иконки и активных/hover-состояний поисковой палитры заменены переменными текущей монохромной темы; клавиатурный фокус явно обозначен.

Основные файлы: `frontend/src/layouts/AppSidebar.tsx`, `AppSidebar.css`, `frontend/src/pages/inbounds/list/InboundList.tsx`, `InboundList.css`, `frontend/src/components/command-palette/CommandPalette.css`.

Проверки: typecheck, lint, frontend build; 20 профильных тестов меню/поиска и обновлённый тест одного нажатия. `hub/ui-point-fixes-browser.mjs` прошёл в светлой и тёмной темах на одноразовой loopback-панели. Проверены переходы, доступность групп, 17 вложенных пунктов, нейтральный цвет поиска, видимый фокус, компактная строка и переключатель. Новых ошибок JavaScript нет. Строка входящих в этой визуальной проверке — тестовый ответ read-only API; реальные подключения и настройки не менялись.

Сопутствующие файлы: версия панели/Windows-установщика и lockfile, ссылки RU/EN README, `NOTICE`, `hub/RELEASE.md`; существующие браузерные проверки адаптированы к независимой стрелке и новой плотности. Сборка и публикация используют существующий Linux packager и формат release assets. Dashboard, протоколы, API, маршрутизация и управление сервером не перерабатывались.
