# Connect Hub — отчёт по UI/UX refinement

## Результат и границы

Реализованы целевые изменения существующего React 19 / Ant Design 6 интерфейса.
Новые UI-библиотеки не устанавливались. Маршруты, backend API, протоколы, база
данных, сетевые настройки, резервное копирование и серверные механизмы обновления
не изменены. Production-развёртывание не выполнялось: это ограничено пунктами
2.2 и 22.6 предоставленного технического задания.

## Основные файлы

- `frontend/src/pages/login/LoginPage.tsx`, `LoginPage.css` — удаление приветствий и их анимации.
- `frontend/src/styles/connect-brand.css` — круглые кнопки, композиция формы, графитовые поверхности, контраст общих Select.
- `frontend/src/hooks/useTheme.tsx` — согласованные токены поверхностей и выбора.
- `frontend/src/layouts/AppSidebar.tsx` — группы существующих маршрутов, состояние раскрытия, упрощённая кнопка поиска.
- `frontend/src/pages/index/OverviewActionBar.tsx` — существующие действия в More, клавиатурное закрытие.
- `frontend/src/pages/index/PanelUpdateModal.tsx` — удаление UI выбора канала без изменения серверного значения.
- `internal/web/translation/{ar-EG,en-US,es-ES,fa-IR,id-ID,ja-JP,pt-BR,ru-RU,tr-TR,uk-UA,vi-VN,zh-CN,zh-TW}.json` — только новые подписи и удаление неиспользуемых строк.
- `frontend/src/test/app-sidebar.test.tsx`, `ui-refinement.test.tsx` — навигация, ручное сворачивание, More, отсутствие скрытых серверных действий/смены канала.
- `hub/ui-refinement-browser.mjs` — браузерная приёмка с запретом опасных запросов.
- `hub/browser-smoke.py`, `hub/brand-browser-check.mjs` — запуск новой приёмки в имеющейся изолированной среде, актуальный цвет темы.
- `.github/workflows/connect-hub.yml` — только сохранение новых скриншотов и JSON проверки в существующем тестовом artifact.

## Ограничения и сохранённый канал

Сохранённое ранее `devChannelEnable=true` продолжает влиять на штатное обновление.
Его нельзя молча сбросить при косметической доработке. UI-переключателя больше
нет; для уже включённого значения сохранено информационное предупреждение.
Для установок на обычном канале предупреждение не показывается. Без отдельного
решения владельца серверное значение и updater API оставлены прежними.
Минимальное последующее решение при наличии такой установки — осознанно сменить
существующий канал через уже имеющиеся настройки/API, отдельной явной операцией.

Визуальная приёмка намеренно не запускает установку обновлений, импорт/экспорт БД,
реальные команды управления Xray или изменение сетевых сущностей. Их обработчики
сохранены; это не заявление о новой проверке всех протоколов на production.
Чтение конфигурации в Windows UI-лаборатории использует тестовый ответ: в ней нет
рабочего Xray-конфига. Изображения внешнего цифрового пространства не были
приложены отдельными файлами к этому ТЗ; использованы текстовые требования и
действующий интерфейс проекта.
